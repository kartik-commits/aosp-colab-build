 FIRST BUILD - STEP BY STEP

1. Download AOSP_Build_Colab.ipynb
 Click the file name
 Right-click → Save as
 Save to your computer
 Or download from Google Drive

2. Open Google Colab
 Visit: https://colab.research.google.com
 File → Upload notebook
 Select AOSP_Build_Colab.ipynb
 Wait for it to load

3. Choose Colab Pro (Recommended)
 Click Runtime → Change runtime type
 Select: GPU T4 with high RAM (Colab Pro)
 Or use free tier (limited storage)
 Click Save

4. Configure Cell 11
 Find cell that has: LUNCH_TARGET = "..."
 Change to your device:
 "cheetah-userdebug" (Pixel 7 Pro)
 "bluejay-userdebug" (Pixel 6 Pro)
 Other options available
 JOBS = 20 (Colab Pro default, reduce if low memory)
 DRIVE_PATH = "/root/gdrive/MyDrive/AOSP" (optional)

5. Run Cells 1-7
 Cell 1-3: Mount Drive, install dependencies (5 min)
 Cell 4-6: Setup build manager (2 min)
 Cell 7-9: Sync AOSP source (30 min) ⏱ LONG WAIT
 Cell 10-11: BUILD! (50 min) MAIN BUILD
 Cell 12-13: Upload results (15 min) UPLOAD

6. Monitor Progress
 Each cell prints status messages
 Cell 7: Should show "Storage: X GB used"
 Cell 11: Should show build percentage
 Final: Should show " BUILD SUCCESSFUL!"
 If error: Check TROUBLESHOOTING.md

7. Check Results
 Open Google Drive
 Look for AOSP/ folder
 Should have:
 out_[timestamp].tar.gz (your ROM!)
 ccache.tar.gz (compiler cache)
 build_state.json (metadata)
 build.log (logs)
 Success!

 COMMON QUESTIONS

Q: Can I pause the build if it hits the 1-hour limit?
A: Yes! The system auto-saves checkpoints. Next session resumes.

Q: How much storage does my first build use?
A: ~200GB total (100-150GB source + 30-50GB build output)

Q: Why does it take so long on first build?
A: Downloading full Android source code takes time.
 Later builds are faster (reuse source + ccache).

Q: Can I build for multiple devices?
A: Yes! Day 1: Pixel 7 Pro, Day 2: Pixel 6 Pro
 They share the same ccache for speed!

Q: What if the build fails?
A: Check TROUBLESHOOTING.md for common issues & fixes.
 Or check build.log in the notebook output.

Q: Can I use free Colab instead of Pro?
A: Yes, but you'll have less storage (100GB vs 200GB).
 You might need to be more selective about what you keep.

Q: How do I get my ROM after building?
A: Download out_*.tar.gz from Google Drive, then:
 tar -xzf out_*.tar.gz
 ROM is in: out/target/product/[device]/*.zip

 IMPORTANT NOTES

1. Google Drive Authorization
 → Colab will ask for Drive access (normal & safe)
 → Grant permission to continue

2. Storage Limits
 → Don't exceed 200GB total on Drive
 → Delete old ROM builds to free space
 → Keep ccache.tar.gz (essential for speed!)

3. Network
 → Make sure you have stable internet
 → Colab to Drive upload is fast (~10 min for 50GB)

4. Runtime Limits
 → Free Colab: 1 GPU allocation per session (~12 hours)
 → Pro Colab: More stable, faster
 → If disconnected: Start new session, resumable
