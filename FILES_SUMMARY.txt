• Storage limit: 200GB total

• Compilation: 20 parallel jobs on Colab Pro is optimal
 Don't exceed 24 (may cause OOM)

 PRO TIPS

1. Always keep ccache.tar.gz on Drive
 → It speeds up rebuilds 2-3x

2. Build different devices with same ccache
 → Lunch "cheetah-userdebug" Day 1
 → Lunch "redfin-userdebug" Day 2
 → They share the same cache!

3. Monitor space with cell 7
 → Run between cells if worried

4. Save build logs
 → Always check /root/aosp/build.log if something fails

5. Use `-j 16` instead of `-j 20` if uncertain
 → Safer, more stable, less OOM risk
